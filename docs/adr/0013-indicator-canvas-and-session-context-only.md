# Indicator ships Structural Canvas and Session Context only

Session POI, Continuation POI, and Active DOL remain how a trader reads the day (ADR-0003, ADR-0008, ADR-0009). The TradingView overlay does not select them, emphasize them, or take Daily Bias, bias direction, or reversal-day TP1 inputs. The chart is Relevant Levels plus Session Context: Daily Open, ADR band, and PD 50% Midpoint. Automating those watches is a later product, not this indicator.

PD Equilibrium Range (25%–75%) stays a Language term and is not computed or drawn.
