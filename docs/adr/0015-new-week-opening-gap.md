# New Week Opening Gap is Session Context, not a Fair Value Gap

The overlay draws the current CME week's New Week Opening Gap as a Session Context box: Friday 17:00 ET daily close to the new week's first open, only when those prints differ by more than four minticks. Geometry is the ICT two-print weekend void labeled in Garrett's English; it is not a three-candle Fair Value Gap, not a Relevant Level, and not Daily Open (which remains the week-open print). Mute and truncate on a 1m wick at or beyond Friday close. The live box projects to the current CME daily session close (17:00 ET) and rolls to the next session close at 18:00, same as Daily Open — not to Friday week end. Keep Daily Open. NDOG is out of scope.

Considered options: treat it as an HTF FVG (rejected — different construction and mitigation); make it a Relevant Level / Active DOL (rejected); draw it later after POI automation (superseded — Session Context already ships on this overlay).
